# 虚拟沙盘 · Virtual Sandbox

> 虚拟沙盘让 NPC 告别脚本：6 名队员全部接入大模型，拥有独立思考——听得懂自然语言命令，也会自行判断战场、主动寻敌。你指挥的不是冰冷单位，而是有灵魂的战友。当 AI 赋予 NPC 思考，即时战术游戏翻开全新范式。

红警风 2.5D 即时战术，纯浏览器运行（Canvas 2D + 原生 ES Modules，零第三方依赖）。你作为"上帝玩家"指挥己方 3 名虚拟成员，摧毁对方指挥所即获胜；对方 3 名成员同样由 AI 驱动。

## 核心特性

### AI 驱动的虚拟成员
- **一人一脑**：每名成员背后是一个独立的 LLM 智能体（默认 DeepSeek），拥有自己的性格人设、武器档案与战术分工（突击手 / 爆破手 / 侦察手 / 重装兵）。
- **自然语言指挥**：打字或按住 V 语音下令。支持点名——「2号 去攻击敌方载具」只由蓝2号执行，其余队员继续手头任务；说「全员」或不说名字才是全班命令。
- **坐标报点**：地图边缘常驻横纵坐标标尺、鼠标处实时显示「格 (x, y)」。报「去(32,20)」即可让成员走到指定格，不受视野限制。
- **命令快车道**：常见命令（移动 / 攻击 / 撤退 / 集合 / 掩体等）由本地规则零 token 当帧解析执行，解析不了才询问 LLM——响应快，又省 token。
- **自主性**：命令执行完毕后成员自动续接自主决策，空闲时主动索敌追击，不会站在原地发呆。
- **队内协同**：共享的战场协同板（敌情 / 求援 / 分工），队友之间会自动集火、支援、包抄，还会互相喊话。

### 战术玩法
- 极简对抗：无采矿无建造，专注指挥本身；胜利目标只有一个——摧毁对方指挥所。
- 对称布景：河流横贯中部、仅三座桥可渡，形成咽喉要道；山包（高地加成）、沙袋阵地（受击减伤）、可摧毁的中立高楼构成天然掩体与争夺点。
- 基地防御：碉堡、炮塔、防空岗拱卫指挥所。
- 武器切换（机枪 / 火箭筒）、乘驾载具（坦克 / 装甲车 / 炮艇机 / 轰炸机，载具被打爆会自动弹射逃生）。
- 编队（Ctrl+数字）、存档读档（F5 / F9）、暂停（Space）。右键选成员、再右键地图下令。
- 上帝视角全图可见，方便观战 AI 的自主行为。

### 成本可控
- 预算面板实时显示 token 消耗；可设置每局 token 上限、每分钟调用上限、决策冷却。
- 超出预算自动降级为脚本 AI（FallbackAI），游戏不中断。
- 默认经本机 `serve.mjs` 转发 LLM 请求（规避 CORS），API Key 只保存在本机浏览器，不经第三方。

## 快速开始

环境要求：Node.js 18+（无第三方依赖，只用内置模块）。

```bash
# 方式一：Windows 一键启动（起服务并自动全屏打开浏览器）
双击 启动沙盘.bat

# 方式二：手动
npm start          # 等价于 node serve.mjs，默认端口 8788
```

浏览器打开 http://localhost:8788 ，在开始界面选择阵营（有右上角全屏按钮）即可开玩。

**配置 AI（可选）**：点击界面上的「⚙ API 配置」打开 config.html，填入 API Key 与模型（默认 DeepSeek）。不配置也能玩——成员会退化为内置脚本 AI，规则与手感一致，只是少了 LLM 的临场思考与台词。

## 开发与测试

```bash
npm test           # 零 API 成本断言（216 项）：命令解析、点名/坐标、成本控制、协同板、视野等
npm run mock       # 启动本地 mock LLM（端口 8899），无需真实 Key 端到端联调
```

mock 用法：`node tools/mock-llm.mjs` 后，在 config.html 里把 API 地址填 `http://localhost:8899/v1`、模型随意（如 `mock`）、Key 填任意非空值，即可完整验证「快照 → 提示词 → 解析 → 执行 → 喊话」链路。

## 项目结构

```
index.html / config.html   游戏入口 / API 配置页
serve.mjs                  静态服务 + /api/llm 转发代理（默认 8788，http 目标仅限本机）
src/
  main.js                  入口：游戏循环与主状态机
  Renderer.js              Canvas 渲染：地图、单位、特效、坐标标尺
  InputHandler.js          鼠标 / 键盘输入与镜头控制
  GameState.js GameMap.js  战场状态与地图
  Combat.js UnitAI.js      战斗结算与单位 AI（引擎层行为）
  Buildings.js Entity.js   建筑逻辑与实体基类
  sandbox/                 沙盘场景、成员名册、成员系统（乘驾 / 弹射 / 掩体高地加成）
  agents/                  LLM 智能体：调度（AgentManager）、提示词（prompts）、
                           决策解析（parser）、降级 AI（FallbackAI）、协同板（squadBoard）、
                           视野（vision）、目标筛选（targeting）、配置（config）
  core/                    会话、命令总线、镜头、布局
  ui/                      成员面板、聊天面板、预算面板、语音输入
tools/
  mock-llm.mjs             本地模拟 LLM 端点（开发调试用，非运行时）
  test-agents.mjs          断言测试脚本
```

## 设计要点

- **模型只出决策，引擎负责执行**：LLM 返回结构化 JSON（说什么、对谁说、做什么、打谁），由引擎校验合法性后落到寻路与战斗系统，非法目标一律丢弃。
- **本地命令优先**：能确定性解析的命令不进 LLM，省 token 且零延迟；LLM 负责的是开放式战术与临场台词。
- **降级即兜底**：断网、超预算、解析失败都会平滑降级到脚本 AI，对局永不卡死。
